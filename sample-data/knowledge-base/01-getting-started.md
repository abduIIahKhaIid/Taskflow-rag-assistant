# Getting Started with TaskFlow

TaskFlow is a fictional project and task management SaaS product for small agencies, consultants, and remote teams. It supports projects, tasks, team collaboration, comments, file attachments, and selected integrations.

## Create a Workspace

A TaskFlow workspace provides the shared area in which a team organizes projects and tasks. Workspace storage depends on the selected plan: Starter includes 5 GB, Pro includes 100 GB, and Business includes 500 GB.

The exact workspace-creation screens, required fields, and role allowed to create a workspace are not defined in the approved product information. Contact TaskFlow support for the current workspace-creation procedure.

## Invite Team Members

Before adding people, review the plan's team-member limit:

- Starter supports a maximum of 10 team members.
- Pro supports unlimited team members.
- Business supports unlimited team members.

TaskFlow provides four roles: Workspace Owner, Administrator, Member, and Viewer. The detailed permissions of these roles, including which roles can invite team members, are not documented. Contact support for current invitation steps and role-assignment guidance. Do not assume a permission based only on a role name.

## Create Your First Project

TaskFlow supports creating and managing projects. Starter allows a maximum of 5 active projects, while Pro and Business allow unlimited active projects.

The approved product information does not define the project-creation fields, templates, status options, or exact interface steps. Contact support if you need the current procedure for creating a project.

## Create and Assign Tasks

TaskFlow supports creating and managing tasks. The approved product information does not define the task-assignment workflow, available task fields, or which roles can assign tasks. Contact support for current instructions before relying on a specific assignment process.

Team members can collaborate through comments. Detailed comment controls and notification behavior are not documented.

## Understand User Roles

TaskFlow uses these role names:

- Workspace Owner
- Administrator
- Member
- Viewer

The only approved role-specific operation is that a Workspace Owner or Administrator must reauthorize a disconnected integration. Other role permissions are not documented. Contact support when a workflow depends on a specific role.

## Upload File Attachments

TaskFlow supports file attachments. The maximum size of an individual attachment is **100 MB**. Supported file-type examples include:

- PDF
- DOCX
- PNG
- JPG
- ZIP

These formats are examples, not a complete list. Support for other file types and the exact attachment-upload steps are not documented. Contact support to confirm an unlisted format or obtain the current upload procedure.

Workspace storage is limited to 5 GB on Starter, 100 GB on Pro, and 500 GB on Business.
